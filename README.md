# KKeyboard downloads

Smart Khmer keyboard by [Somara AB](https://www.somara-ab.com/en/products/kkeyboard).
Type Khmer the way it sounds in Latin letters, or in partial Khmer, and pick
from the suggestions. Free to use.

This repository only hosts installers. The source code is not public.

## Install on Windows

1. Download and run `KKeyboardSetup-x64.exe`.
2. If Windows SmartScreen appears, choose **More info → Run anyway**.
3. Switch to **Khmer – KKeyboard** with <kbd>Win</kbd> + <kbd>Space</kbd>.
4. Open **KKeyboard Settings** from the Start menu to change suggestion and font options.

To uninstall, go to **Settings → Apps → Installed apps → KKeyboard**.
